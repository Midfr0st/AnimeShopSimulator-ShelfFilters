# История изменений

## 0.10.5 — 2026-10-20

Совместимость с Anime Shop Simulator 1.0.74.

- Обновлены три вызова FindNearestDroppedReturnPlace: учтён новый параметр requireReachable.
- Устранён MissingMethodException, из-за которого выкладчики переставали искать задания.
- Проверка места возврата использует штатную проверку доступности полки для работника.
- Кэш результата проверки разделён по работнику и товару, чтобы разные работники не использовали чужой результат доступности.
- Проверка заполненной секции перенесена на следующий кадр и повторно проверяет коробку и задание: возврат на склад больше не запускается на последнем товаре одновременно с выбрасыванием пустой коробки.

Проверены сборка без ошибок и предупреждений и разрешение всех 150 проверенных прямых обращений установленных модов к API игры. В короткой игровой проверке восстановлена работа выкладчиков; подтверждено успешное удаление восьми пустых коробок у двух работников без конфликтов заданий и ошибок. Длительная игра и кооператив отдельно не проверялись. Для работы требуется WolfCore 0.2.6.

## 0.10.4 — 2026-10-03

Совместимость с Anime Shop Simulator 1.0.7.

- Восстановлена работа выкладчиков с установленными фильтрами полок после обновления игры до 1.0.7.
- Все три вызова поиска места возврата коробки адаптированы к изменённому API игры. Устранён повторяющийся MissingMethodException, из-за которого выкладчики стояли без работы.
- Обновлены сведения о совместимости и зависимости от WolfCore 0.2.6.

Сборка и короткая игровая проверка основных сценариев прошли успешно. Для модулей используйте WolfCore 0.2.6.
