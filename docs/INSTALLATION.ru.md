# Установка фильтров полок

[Вернуться на главную страницу](../README.md)

## Требования

- Anime Shop Simulator для Windows;
- [MelonLoader](https://github.com/LavaGang/MelonLoader) `0.7.3`;
- [WolfCore](https://github.com/Midfr0st/AnimeShopSimulator-WolfCore) `0.2.6` или совместимая версия.

## Установка

1. Закройте игру.
2. Установите MelonLoader и один раз запустите игру.
3. Скачайте `WolfCore.dll` из [выпуска WolfCore](https://github.com/Midfr0st/AnimeShopSimulator-WolfCore/releases/latest).
4. Скачайте `AnimeShopShelfFilters.dll` из [выпуска мода](https://github.com/Midfr0st/AnimeShopSimulator-ShelfFilters/releases/latest).
5. Поместите обе DLL непосредственно в `Anime Shop Simulator\Mods`.

Не оставляйте в `Mods` старые или переименованные копии DLL.

## Проверка

После загрузки сохранения откройте `Esc` → `Моды`. В списке должны отображаться WolfCore и `Фильтры полок`. Наведитесь на товарную секцию и нажмите назначенную клавишу, по умолчанию `F6`.

## Обновление

Заменяйте DLL только при полностью закрытой игре. Файлы правил и настроек в `UserData` сохраняются.

## Удаление

Удалите `Mods\AnimeShopShelfFilters.dll`. Для полного сброса можно дополнительно удалить оба файла `AnimeShopShelfFilters` из `UserData`; игровое сохранение это не затрагивает.
