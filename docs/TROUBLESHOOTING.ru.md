# Решение проблем

[Вернуться на главную страницу](../README.md)

## Мод не появился в меню

- проверьте наличие `Mods\WolfCore.dll` и `Mods\AnimeShopShelfFilters.dll`;
- убедитесь, что MelonLoader запускается;
- удалите дубликаты DLL;
- проверьте версии игры, WolfCore и мода в `MelonLoader\Latest.log`.

## Клавиша не открывает окно

- наведитесь именно на секцию, куда можно положить товар;
- попробуйте секцию, в которой есть свободное место;
- проверьте назначенную клавишу через `Esc` → `Моды` → `Фильтры полок`.

## Выкладчик остановился с товаром

1. Закройте игру и сохраните `MelonLoader\Latest.log`.
2. Проверьте, есть ли совместимое свободное место для товара из коробки.
3. Временно переключите проблемную секцию на штатное правило игры.
4. Приложите лог, скриншот, название товара и тип мебели к отчёту в Issues.

Не устанавливайте одновременно разные версии мода.
